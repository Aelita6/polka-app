    Синхронизация iPhone ↔ Mac

    Полка будет храниться в вашем приватном репозитории GitHub и одинаково открываться на всех устройствах. Нужен ключ доступа — создаётся один раз.

    1. Откройте страницу создания ключа.
    2. Token name: Полка. Expiration: самый долгий срок (или No expiration).
    3. Repository access → Only select repositories → polka-data.
    4. Permissions → Repository permissions → Contents: Read and write.
    5. Нажмите Generate token, скопируйте ключ и вставьте ниже.

    Чтобы подключить iPhone: наведите камеру телефона на QR-код и откройте ссылку. Ключ вводить не придётся. Никому эту ссылку не отправляйте.
